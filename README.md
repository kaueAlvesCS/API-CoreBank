## 📖 Sobre o Projeto

O **API-CoreBank** é uma plataforma de gestão financeira desenvolvida com foco estrito na **integridade de dados**, segurança transacional e aplicação rigorosa de **regras de negócio bancárias**. 

O objetivo do projeto é simular o núcleo (core) de um sistema financeiro moderno, garantindo consistência em operações, controle de contas e confiabilidade nas informações transacionais.

---

## 🚀 Funcionalidades (Roadmap)

O projeto está em constante evolução. Abaixo estão os principais módulos planejados e em desenvolvimento:

- [ ] **Gestão de Contas:** Abertura, gerenciamento e consulta de saldos.
- [ ] **Transações Seguras:** Validação de regras para transferências, depósitos e saques.
- [ ] **Integridade Transacional:** Garantia de consistência e prevenção de inconsistências financeiras.
- [ ] **Autenticação e Permissões:** Proteção de rotas e controle de acesso de usuários.

## 🛠️ Tecnologias Utilizadas

A arquitetura do projeto separa as responsabilidades entre backend, frontend e documentação:

### ⚙️ Backend
- **Node.js / TypeScript**
- **Prisma ORM** (Modelagem, migração e manipulação do banco de dados)
- Banco de Dados Relacional

### 🎨 Frontend
- **React** (Interface de usuário para gestão financeira)
